# Quantifying time-dependent Media Agenda and public opinion by topic modeling, Sebastián Pinto a

## 요약
뉴스(미디어)가 어떤 "토픽"을 얼마나 다루는지대중이 그 토픽에 얼마나 관심 갖는지 같은 토픽공간에서 정량화, 시간에 따라 다양성(엔트로피)와 유사성(JS distance)가 어떻게 움직이는지 측정
## 연구질문
1. 미디어 의제와 대중 의제의 시간에 따라 어떻게 변하나?
> 미디어 의제와 대중의제의 대상은 누구?
2. 대중 관심은 미디어의 토픽 분포를 따라가나? 혹은 특정 이슈에서 어긋나나?
> 대중 관심의 측정법? 특정 이슈에서 특정이슈에 대해 분석하나?
3. 매체별로 같은 이슈를 다루는 방식(covergage bias)이 정량적으로 드러나나?
> 방식이 어떤 방식을 이야기하는거지?
4. 특정 이슈에서 소셜미디어-대중-전통미디어 사이에 피드백이 관찰되나?
> 논문에서 정의되는 피드백의 형태는?
## 데이터/사례
- 대상 아르헨티나 정치뉴스 
- 기간 2017-07-31 ~ 2017-11-05 (3개월)
- 매체 Clarín, La Nación, Página12, Infobae (온라인 정치 섹션)
- 기사 수: 총 11,815개
- Public agenda(대중관심 지표(대중 관심의 대리변수)): Google Trends 검색량 + Twitter - 키워드 검색(표본 트윗을 일별로 수집, 총 24,360개)
> 트위터 키워드 검색이란?
> 대중관심의 지표로써 합당한가?
## 방법(핵심 설계)
### (A) 토픽 모델링: TF-IDF + NMF
> NMF가 
1. 기사 텍스트 TF-IDF 벡터로 만들기
2. NMF로 문서-단어 행렬을 토픽공간으로 분해해서
   - 각 문서가 토픽에 "얼마나" 속하는지(H행렬)
   - 각 토픽을 설명하는 단어 조합(W행렬)
> LDA대신 NMF가 "비음수 제약이 해석이 유리해서?"
### (B) Agenda 정의 방식
- Media Agenda: 특정 날짜에 각 토픽이 차지하는 "가중치" 분포
> 가중치가 비율로써 나오나? 아 분포니깐? 아 밑에 정규화한다고 하네
  - 가중치 = (H행렬) X (기사 길이) 형태로 정의
  > 기사길이는 왜 곱하는거지?
  - 노이즈 제거 위해 3일 슬라이딩 윈도우로 평활화 후 정규화
  > 선형회귀 했다는거지?
- Public Agenda: 같은 토픽 키워드로
  - Google Trends의 상대 검색량 분포
  > 상대 검색량은 비율 이야기하는건가?
  - Twitter의 일별 트윗 표본에서 키워드 비중을 추정해 분포 구성
- **토픽공간이 "미디어에서 나온 토픽"  임으로 안나온 토픽인 대중이슈는 못 잡는다.
#### (C) 비교 지표
1. 의제 다양성: Shannon entropy로 측정(토픽 골고루면 높고 독점하면 낮다)
2. 의제 차이(거리): Jensen-Shannon distance로 Media vs Public 분포 차이를 측정

## 결과
1. 대중 의제는 미디어 의제보다 덜 다양하다.  
엔트로피 시계열에서 아마 Public Agenda가 Media Agenda보다 더 자주/더 크게 하락 하는 패턴 보여줌
2. Media-Public 간 어긋남이 커지는 순간(==JS distance 커짐)이 있고, 그 원인을 토픽 분포로 추정했을 때 특정 토픽에 대한 대중 관심 급증
3. 매체별 Coverage bias가 레이더 플롯으로 가시화
4. "피드백" 사례: 소셜 미디어 캠페인 -> 대중 관심 급증 -> 전통미디어  
"Missing Person" 토픽에서, 특정 시기(8월 전후) 대중(구글/트위터)가 먼저 뛰고 미디어 반응이 느리게 따라오는 구간을 관찰  
매체별로도 Página12가 더 빠르게 반응했던 흔적 바탕으로 "복잡한 상호작용" 가능성  
대중 -> 판매량 적은 언론-> 대형 언론
## 한계
1. 피드백 사례가 상호작용으로 발달 가능한가 -> 연관성 증명 고민, 즉 인과가 합당한가?
2. 미디어에 잡히지 않은 대중 이슈는 포착불가 -> 미디어에서 토픽공간을 만든것과 대중이슈에서 만든 것을 같이 교차해서 보는 방안?
